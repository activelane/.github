# ActiveLane organisation files

This directory is ready to use as the contents of the public `activelane/.github` repository.

## Structure

```text
.github/
├── profile/
│   └── README.md
├── README.md
├── CONTRIBUTING.md
├── CODE_OF_CONDUCT.md
├── SECURITY.md
├── SUPPORT.md
├── GOVERNANCE.md
├── ROADMAP.md
└── PULL_REQUEST_TEMPLATE.md
```

GitHub displays `profile/README.md` on the public organisation page. The other files provide organisation-wide defaults where a repository does not define a more specific version.

Before publishing, enable GitHub private vulnerability reporting for every security-sensitive public repository.
