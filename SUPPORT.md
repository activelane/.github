# ActiveLane Support

ActiveLane is early-stage, experimental software maintained by a solo developer. Community support is currently best-effort.

## Where to ask

Use the most specific channel available in the relevant repository:

- **Bug report:** open an issue using the bug template.
- **Feature or product proposal:** begin with a discussion or proposal issue.
- **Development question:** use repository discussions when enabled.
- **Documentation problem:** open a focused documentation issue.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md); never disclose it publicly.
- **Conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Before opening an issue

Please search existing issues and include:

- the affected repository and version or commit;
- operating system and host, such as Web or Wails Desktop;
- exact reproduction steps;
- expected and observed results;
- relevant logs with secrets and personal data removed;
- and a minimal reproduction when practical.

Screenshots can help explain visible behavior, but text reproduction steps and logs are still needed.

## What is not currently offered

Unless a written agreement says otherwise, ActiveLane does not currently provide:

- guaranteed response or resolution times;
- production SLAs;
- paid implementation support;
- migration guarantees for pre-stable APIs;
- security certification;
- or support for unofficial forks and modified packages.

Commercial and enterprise support may be introduced later, after the project has the people and operational capacity to provide it responsibly.

## Response expectations

Issues may be prioritised by severity, reproducibility, user impact, security risk, alignment with the active milestone, and the availability of a sustainable fix. Not every requested feature will enter the roadmap.
